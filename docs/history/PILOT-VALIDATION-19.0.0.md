# Pilot Validation Plan — 19.0.0

Recommended pilot: 20–50 players, at least two device/browser classes, with a small group deliberately using unstable network conditions.

Capture per session: build version, device/browser, FPS/stutter notes, combat mode, Pow team, Domain used, reconnect result, reward result, duplicate/replay anomalies, and any console/runtime error.

Exit criteria: no reward duplication, no save rollback/corruption, no reproducible stale-client double action, reconnect restores exact authoritative PvP match, all 9 Domains behave server-authoritatively, and no critical 60-FPS regression on supported hardware.
