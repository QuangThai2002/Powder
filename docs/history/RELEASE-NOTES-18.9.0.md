# Powder 18.9.0 — Combat Content Expansion

- Adds real Elite affixes rather than simple stat reskins.
- Adds selective Dungeon modifiers and element-relevant battlefield weather.
- Adds Boss modifiers on top of the existing phase/signature system.
- Adds three rule-based Challenge Combat encounters.
- Adds three five-enemy PvE Gauntlets using 3 active + 2 reserve.
- Adventure UI now shows active combat modifiers before entering a stage.
- Admin now includes a Combat Content catalog for auditing the new content layer.
- Challenge/Gauntlet are intentionally no-reward until dedicated Server Reward Authority policies are added.
- Existing Event Combat remains Server Combat authoritative; client-only modifiers never mutate a server session.
