# Powder 20.19.0 — Release Candidate / Canary

20.19.0 chuyển Powder từ RC1 automated regression sang candidate có thể rollout thật. Bản này không thêm gameplay. Nó thêm RC evidence cho đúng artifact, rollback drill bắt buộc, stage timer và policy health tăng dần cho 5% → 20% → 50% → 100%. Stage health chỉ do server tính từ Observability; client/Admin không thể tự nhập PASS.
